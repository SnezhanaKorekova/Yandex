# 🗺️ Yandex Maps API Viewer (Большая задача по Maps API)

Небольшое Desktop-приложение на Python для работы с картами, созданное с использованием библиотеки PyQt5 и Yandex Maps API. Проект позволяет просматривать карту, осуществлять навигацию, менять слои и искать конкретные географические объекты с установкой маркеров.

## 🌟 Возможности приложения

- **Навигация:** Перемещение по карте с помощью кнопок (Вверх, Вниз, Вправо, Влево).
- **Масштабирование:** Изменение масштаба отображения (кнопки PgUp / PgDown).
- **Слои карты:** Поддержка трех видов отображения:
  - Схема (стандартная карта)
  - Спутник
  - Гибрид (спутник с названиями объектов)
- **Поиск объектов:** Поиск любого топонима (города, улицы, здания) через Yandex Geocoder API.
- **Отображение данных:** Установка метки (пина) на найденный объект и вывод его полного адреса.
- **Очистка результатов:** Кнопка сброса для удаления метки и очистки строки адреса.

## 📁 Структура проекта

- `task_1.py` — главный файл приложения, содержащий логику графического интерфейса (PyQt5) и обработку событий.
- `find_place.py` — модуль интеграции с Yandex Geocoder API (преобразование текстового названия места в координаты).
- `s.py` — модуль работы с Yandex Static Maps API (формирование запросов, загрузка тайлов/изображений карты в файл `map.png` и управление метками).

## 🚀 Установка и запуск

1. Убедитесь, что у вас установлен Python версии 3.x.
2. Установите необходимые зависимости:
   ```bash
   pip install PyQt5 requests
   ```
3. Запустите главный файл:
   ```bash
   python task_1.py
   ```
4. **Важно:** При запуске программа сначала попросит ввести начальные данные в консоли (терминале):
   - Координаты в формате `x,y` (например, `37.6173,55.7558` для Москвы).
   - Масштаб в формате числа (например, `0.02`).
   После ввода откроется графическое окно приложения.

## 🛠️ Технологии

- **Python**
- **PyQt5** (GUI)

- **Yandex Geocoder API**
- **Yandex Static Maps API**

## ⚠️ Примечание для разработчиков (Security)
В файле `find_place.py` используется захардкоженный API-ключ Яндекса. В рамках учебного проекта это допустимо, но для production-решений рекомендуется выносить ключи в переменные окружения (например, используя библиотеку `python-dotenv`).
